## 版本号

`Beta_0.0.1`

产物：`Minecraft-DG-LAB-Connect-26.3-Fabric-Beta_0.0.1.jar`（模组版本 `0.0.1`，通道 `Beta`，Minecraft 26.3 / Fabric；清单内版本 `0.0.1-beta`）

## Update Log

- 与 `Alpha_0.0.1` 为同一份代码的 Beta 通道构建，仅通道标记不同
- 新增受伤 → 设备联动：通过已配对的 SOCKET V3 连接下发通道强度与波形，强度跟随受伤面板数值
- 波形改为排队播放，新增「最大排队 秒」（默认 6 秒 = 60 帧），队列满后新事件整条丢弃直到腾出空间
- 删除强度映射，界面数值统一为下发强度；基准点数更名为基础强度
- 受伤面板仅在设备已连接时显示，并受受伤提示开关控制
- 新增独立死亡事件（独立通道 `dglab:own_death_hud`，默认 +100、潮汐），修复与旧客户端混用时 custom_payload 解码掉线
- 新增 `/dglab menu` 图形设置：反馈与设备页、来源页、死亡事件行；数字项支持直接输入，关键项带悬浮说明
- 51 种原版伤害来源汉化，未知来源回退原始 id
