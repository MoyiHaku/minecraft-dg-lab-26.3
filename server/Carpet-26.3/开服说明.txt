Minecraft Java 26.3 生电服 · Windows 10 / 11 x64
Fabric Loader 0.20.1  |  Java 25 自带

第一次开服
1. 完整解压 ZIP 到可写文件夹，例如 D:\Minecraft\Carpet-26.3，再打开那个文件夹。
2. 双击 start.bat。读完窗口给出的 Minecraft 最终用户许可协议，如果同意，输入 Y 后按回车。
3. 首次会从 Mojang 下载约 59.4 MiB 的原版 server.jar，并校验完整性。Fabric、模组和 Java 已随包提供。
4. 等到控制台出现 Done，打开 Minecraft Java 26.3，进入「多人游戏 → 直接连接」。
   在开服电脑上填写 localhost；同一局域网的朋友填写开服电脑的局域网 IPv4，如 192.168.1.20。
   默认端口 25565/TCP。其他网络的朋友需要有能访问的地址和端口；双击开服仅启动本机服务。
   从 Windows 的 ipconfig 输出能找到当前正在使用的网络适配器的 IPv4。

第二次开始，直接双击 start.bat，原版服务端和已有世界会自动复用。
关服时，在服务端控制台输入 stop 并等保存完毕。存档在 world 文件夹。
同一个目录只能同时运行一个服务端；多个窗口会收到提示。

本包的生电设置
困难生存；视距 10、模拟距离 10、出生点保护半径 0、最多 20 人，分配给服务端的 Java 堆为 1–4 GiB。
无人时服务器继续跑刻。农场能否运行还取决于区块加载、玩家距离及具体机制。
已开启正版验证。白名单默认关闭。如果只希望朋友能加入，可在控制台依次执行：
  whitelist add 你的Java版角色名
  whitelist add 朋友的Java版角色名
  whitelist on
修改内存可在关服后编辑 jvm-args.txt 的 -Xmx4G；其余服务端设置在 server.properties。

在控制台输入 op 你的Java版角色名，便可在游戏里管理本服。以下是游戏内命令，控制台命令省略开头的斜杠。
  /log tps                             显示服务器性能
  /player Bot spawn                    在当前位置生成名为 Bot 的假玩家（若重名请换名）
  /player Bot kill                     移除该假玩家
  /carpet setDefault hopperCounters true   持久启用漏斗计数器；让漏斗向染色羊毛方块输出
  /counter                             查看计数结果
  /lifetime help                       查看实体生命周期追踪帮助
  /tick query                          查看服务器刻速
Carpet 与 TIS 的玩法规则保留各自发布版本的默认值，服主可按机器的需求逐项启用。

DG-LAB 服务端读数
本包已安装 Minecraft-DG-LAB 只读状态同步，模组版本 1.2.7+status.26.3.3。服务器继续使用原来的游戏端口 25565。
要使用该功能的玩家，在启动器导入 client/Minecraft-DG-LAB-26.3-Fabric-Status.mrpack。手机与玩家自己的游戏电脑处于同一局域网即可。
玩家进服后输入 /dglab share on，用 DG-LAB 3.x App 扫描游戏左上角的二维码。已有配对可直接开启共享。
玩家用 /dglabserver status 核对本服读数。控制台用 dglabserver list 列出正在共享的人，用 dglabserver status 玩家名 查看 A/B 当前值与上限。
用 /dglab share off 停止共享，或 /dglab disconnect 断开手机。离服后自动清除读数，下次进服由玩家重新开启共享。
模组仅接收通道读数。设备刺激输出及 KubeJS 控制未包含在本版。原版玩家仍可正常加入。

本玩家受伤 HUD
新版本在本人受到游戏伤害时显示画面反馈。手机配对和读数共享均为选用。
进服后输入 /dglab feedback 查看设置。/dglab feedback waves 列出 16 种预设，点名称可填入选择命令。/dglab feedback preview 潮汐 可单独预览。
只看跌落时依次输入 /dglab feedback sources none 和 /dglab feedback source minecraft:fall on。
用 /dglab feedback source minecraft:fall step 15 设为每次增加 15 点，用 /dglab feedback source minecraft:fall wave 潮汐 选择曲线。step 也接受负数。
画面反馈计量为 0–100，实际 A/B 来自手机回报。服务端只接收玩家主动共享的 A/B 读数。

升级已有服和存档
在原服控制台输入 stop，等它保存退出。将本包 mods 中的 Minecraft-DG-LAB-26.3-Fabric-Status.jar 放入原服 mods，替换同名旧版，然后双击原服的 start.bat。只需更新这个模组，存档和现有配置沿用原目录。

其他可选客户端功能
原来的 DGLab Craft 画面反馈模组在 client 目录。它提供受伤、低血量和环境提醒，详情见 client/客户端说明.txt。

启动遇到问题
• 窗口提示解压不完整：从 ZIP 完整解压后再启动；start.bat、runtime、tools、mods 和 libraries 应在同一层。
• 下载失败：恢复网络后再双击。也可以从下方 Mojang 链接下载为本目录的 server.jar，启动时会自动校验。
• 提示校验不符：将旧 server.jar 移出目录后再启动，保留 world。
• 端口已占用：先停止占用 25565 的旧服，或改 server.properties 的 server-port 并使用新端口连接。
• 本机能进、局域网连不上：在 Windows 防火墙允许专用网络访问本服务端，检查双方使用的 IPv4 和端口。
• 服务端日志保存在 logs/latest.log。启动器和模组版本固定，重启不会升级世界格式。
